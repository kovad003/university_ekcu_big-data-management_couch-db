## Interpretation

- D1: an update that names a stale revision gets HTTP 409, and the earlier successful update stays. Optimistic concurrency per document prevents lost updates.
- D2: _bulk_docs returned HTTP 201 overall but reported per item: bulk-a saved, bulk-b rejected with a conflict. A bulk request is a batch, not an all-or-nothing transaction.
- D3: in the shop, 'create order + decrement stock' sent together can half-succeed. Invariants spanning two documents need application logic (retry, compensation) or a single-document design.
- This is about the local transaction boundary. How fast revisions reach another instance is a separate question (experiment B).
