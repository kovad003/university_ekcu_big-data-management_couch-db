## Interpretation

- Every write returned a new revision (1-, 2-, 3-). An update must quote the current _rev, so a client cannot silently overwrite a version it has not seen (see experiment D1).
- Delete creates a tombstone revision rather than erasing the document, so a replica can learn about the deletion.
- The Mango query used the (tenant, status, created_at) index and returned exactly the documents a full client-side scan finds, newest first.
